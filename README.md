# YouTube 제작 자료

곁든날에서 운영하는 서비스의 YouTube 공개 자료를 보관합니다.

| 디렉터리 | 콘텐츠 |
|---|---|
| [yomi-calendar](yomi-calendar/) | 요미 캘린더 영상·썸네일·자막·게시 문구 |
| [olumpos-english-radio](olumpos-english-radio/) | 올룸포스 잉글리시 라디오 웹툰 영상·음성·자막 |

콘텐츠마다 별도 폴더를 만들고 영상, 이미지, 자막, 게시 문구, 출처를 함께 관리합니다. 공개용 결과물만 추가하며 계정 인증정보, 개인 기록, 내부 자료는 포함하지 않습니다.

이 저장소에 파일을 추가하는 것은 YouTube 게시와 별개입니다. 게시 후 해당 콘텐츠 README에 영상 주소를 기록합니다.

공개 열람이 가능한 저장소이며, 콘텐츠에 일괄적인 오픈소스 이용 허락을 부여하지 않습니다. 외부 음악 등 제3자 자료에는 각 콘텐츠의 출처·라이선스가 적용됩니다.
